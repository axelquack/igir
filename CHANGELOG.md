# Changelog

This file is published with a public repository.

It must never contain IP addresses, hostnames, MAC addresses, internal paths, usernames, email addresses, vault IDs, credentials, or pane IDs.

Newest first.

The format is inspired by [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/).
Dates are Europe/Berlin, `YYYY-MM-DD`. This repository does not use Semantic Versioning.
Group bullets under the categories that apply: Added, Changed, Deprecated, Removed, Fixed, Security. Omit empty categories.


Use one heading per change: `## YYYY-MM-DD — title`. Under it, keep only the subsections that have items. End with a Why line.
